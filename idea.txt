Movie Theatre Management System

1. Project Overview
Description:
A comprehensive software solution designed to streamline operations for multiple movie theatres. The system will manage theatre profiles, screen configurations, show scheduling, ticket sales, and reporting in a single platform.
Objectives:
Simplify the management of multiple theatre locations.
Improve operational efficiency with automated scheduling and ticketing.
Enhance customer experience through an intuitive booking system, personalized recommendations, and the ability to provide movie feedback.
Scope:
Included: Theatre and screen management, movie scheduling, online ticketing, payment processing, reporting/analytics, and customer feedback collection.
Excluded: In-depth mobile app development (initial release), physical hardware integrations, and external facility maintenance.

2. Problem Statement
The Problem:
Many movie theatre chains struggle with fragmented systems that lead to scheduling conflicts, inefficient ticketing processes, and inconsistent customer experiences. Manual operations often result in errors and slow responsiveness.
Target Audience:
Theatre chains, independent cinemas, and multi-location movie theatre operators looking to optimize their operations and deliver a seamless customer experience while gathering valuable insights from customer feedback.

3. Key Features and Functionalities
Staff Features
Theatre & Screen Management:
Description: Centralized administration of theatre locations, individual screen configurations, and customizable seating arrangements.
User Benefit: Reduces manual setup time and minimizes scheduling errors across multiple venues.
Show Scheduling & Booking Management:
Description: Enables staff to create and manage movie showtimes, ensuring real-time updates on seat availability and preventing scheduling conflicts.
User Benefit: Streamlines operations and provides accurate scheduling information for both staff and customers.
Customer Features
Ticket Booking:
Description: Allows customers to manually select seats and book tickets for a chosen showtime. This feature supports a detailed seat selection process, ensuring that customers can choose their preferred seating arrangement.
User Benefit: Offers a personalized booking experience where customers can visually inspect available seats and make informed decisions about their seating.
Technical Implementation:
Seat Map Integration: Display an interactive seat map for each screen, showing real-time availability.
Booking Flow: Enable customers to select one or more seats, review the booking details, and proceed to payment.
Data Synchronization: Update seat availability in real time to prevent double-booking and ensure data consistency.

## 🗂️ Backend Project Structure (Feature-Based)
```
backend/
├── src/
│   ├── main/java/com/example/movietheatres/
│   │   ├── common/             # Shared constants, enums, exceptions
│   │   ├── config/             # CORS, Security, JWT, etc.
│   │   ├── features/
│   │   │   ├── auth/           # Login, Register, Token, etc.
│   │   │   ├── users/          # User base class, Staff & Customer logic
│   │   │   ├── theatres/       # Theatre, Screen
│   │   │   ├── showtimes/      # Showtimes management
│   │   │   ├── bookings/       # Booking, BookingSeat, Seat logic
│   │   │   ├── payments/       # VNPay integration
│   │   │   └── schedulers/     # Cleanup tasks after showtime
│   │   └── shared/             # Shared DTOs, responses, and utils
│   └── resources/
│       └── application.yml
├── pom.xml
```
