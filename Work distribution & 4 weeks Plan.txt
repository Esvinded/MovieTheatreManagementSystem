## 🗂️ Backend Project Structure (Feature-Based)
```
backend/
├── src/
│   ├── main/java/com/example/movietheatres/
│   │   ├── common/             # Shared constants, enums, exceptions
│   │   ├── config/             # CORS, Security, JWT, etc.
│   │   ├── features/
│   │   │   ├── auth/           # Login, Register, Token, etc.
│   │   │   ├── users/          # User base class, Staff & Customer logic
│   │   │   ├── theatres/       # Theatre, Screen
│   │   │   ├── showtimes/      # Showtimes management
│   │   │   ├── bookings/       # Booking, BookingSeat, Seat logic
│   │   │   ├── payments/       # VNPay integration
│   │   │   └── schedulers/     # Cleanup tasks after showtime
│   │   └── shared/             # Shared DTOs, responses, and utils
│   └── resources/
│       └── application.yml
├── pom.xml
```

## 🌐 Frontend Dev Plan (4 Weeks)


| Week | Focus | FE Dev 1 (Auth/Profile/Layout) | FE Dev 2 (Booking Flow) |
|------|-------|--------------------------------|--------------------------|
| **Week 1** | Setup | Init Vite + Tailwind, Routing, Auth UI | Seat Map UI, Page Routing |
| **Week 2** | Auth & Booking | Login/Register logic, Route Guards | Booking flow + API integration |
| **Week 3** | Payment | Profile edit, JWT storage | VNPay integration, timeout logic |
| **Week 4** | Polish & Test | Layout polish, error states, QA | Real-time update, final testing |


### ✅ Weekly Milestones
- **Week 1**: Routing + UI skeletons working
- **Week 2**: Auth working, seat selection integrated
- **Week 3**: Payment works, real bookings functional
- **Week 4**: Clean, real-time, tested app
